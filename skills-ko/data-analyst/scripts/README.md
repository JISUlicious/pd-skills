# 진단 프로브

`SKILL.md`가 요구하는 모델링 전 진단의 실행 가능한 버전입니다. 참조 파일들이
방법을 설명한다면, 이 스크립트들은 그것을 실행합니다. 검사를 인라인으로 다시
구현하기보다 프로브를 실행하세요 — 프로브가 권위 있는 구현이며, 그 종료
코드는 CI와 분석 중인 에이전트가 모두 근거로 삼을 수 있습니다.

이들은 **프레임워크 프로브**입니다. 시그니처가 고정되어 있고 데이터셋에 따라
달라지지 않습니다. 작업별 분석 코드(특정 EDA 패스, 특정 이상에 대한 RCA
스크립트)는 여전히 작업마다 작성합니다 — 문서 하단의 범위 항목 참조.

## 각 프로브가 단언하는 것

| 프로브 | 통과 조건 | 실패의 의미 |
|---|---|---|
| `collinearity_probe.py` | 어떤 피처도 다른 피처와 중복되지 않음 — 모든 VIF가 심각 임계값 미만이고 결정적인 교차 타입 결속이 없음 | OLS β의 부호가 재실행마다 뒤집히고, 중복 클러스터 내에서 "최상위 드라이버"는 임의적임 |
| `null_audit_probe.py` | 모든 칼럼이 완전하거나, 그 결측이 타깃에 대한 신호를 담고 있지 않음 | `dropna()`가 표본을 자기선택된 하위 집단으로 축소함. 이후의 모든 계수는 모집단이 아니라 그 하위 집단을 설명함 |
| `leakage_probe.py` | 타깃을 재진술하는 피처가 없고, 요약 롤업이 자신의 구성 요소를 가리지 않음 | 모델의 최상위 드라이버가 동어반복이며 R²는 관계가 아니라 항등식을 측정함 |
| `cluster_representative.py` | 모든 다중공선 클러스터가 방어 가능한 대표 하나로 정리됨 | 최소 한 클러스터가 실질적 동점 — 여기서 임의로 고르면 분석의 결론이 조용히 바뀜 |
| `premodel_audit.py` | 진단 4종 전체 통과 (위 세 가지 + 타깃 왜도) | 어느 항목이 막았는지 개별 출력에 표시됨 |

## 사용법

```bash
python scripts/premodel_audit.py data.csv --target SalePrice      # 단일 판정
python scripts/collinearity_probe.py data.csv --target SalePrice  # 개별 검사
python scripts/premodel_audit.py data.csv --target y --json       # 기계 판독용
```

공용 플래그: `--target`, `--exclude 칼럼 …`, `--sample N`(시드 고정), `--json`.
각 프로브의 고유 임계값은 `-h`로 확인하세요.

CSV, TSV, Parquet, Excel, JSON/JSONL을 지원하며 확장자로 판별합니다.

## 종료 코드

| 코드 | 의미 |
|---:|---|
| 0 | 검사 통과 |
| 1 | 검사 실패 — 호출자가 조치해야 할 실제 발견 |
| 2 | 프로브 실행 불가 (잘못된 경로, 읽을 수 없는 파일, `--target` 누락) |

1과 2의 구분이 중요합니다. "데이터에 문제가 있다"와 "들여다볼 수 없었다"는
CI에서도 에이전트에서도 다른 대응을 요구합니다.

## 의존성

1차 계층만 사용합니다 — `pandas`, `numpy`, `scipy`. Parquet은 `pyarrow`,
Excel은 `openpyxl`이 추가로 필요하며 둘 다 공용 집합에 속합니다. 리더가
없으면 트레이스백 대신 사용 오류로 보고합니다.

scikit-learn, xgboost, shap, statsmodels는 어떤 프로브에도 필요하지 않습니다.
그것들은 프로브가 통제하는 모델링 단계에 속하지, 통제 장치 자체에 속하지
않습니다.

## 출력을 정직하게 읽기

**ID 칼럼을 제외하세요.** 행 인덱스나 레코드 ID는 행 순서에 단조인 무엇과도
완벽히 공선이며, 아무 의미 없이 VIF 표를 장악합니다:
`--exclude "Unnamed: 0" Order PID`.

**구조적 부재는 결측이 아닙니다.** NaN이 "기록되지 않음"이 아니라 "해당
없음"을 뜻할 때 — Ames의 `Pool QC`가 null인 이유는 수영장이 없기 때문입니다 —
`null_audit_probe.py` 실행 전에 명시적 레벨로 인코딩하세요. 그러지 않으면
프로브는 실제로는 온전히 유익한 칼럼을 버리라고 정확하지만 무익하게
권고합니다.

**VIF에는 행이 필요합니다.** 행 수가 피처 수 + 2보다 적으면 계수 행렬의 랭크가
부족해 모든 VIF가 산술적 이유로 무한대가 되므로, 이 프로브는 VIF 계산을
거부합니다. n/p < 10이면 추정이 불안정하다고 경고합니다. 넓은 센서 데이터는
도메인이나 클러스터로 먼저 좁히세요. 기본값은 `--max-features`가 지킵니다.

**연관 측도는 dtype 조합을 따릅니다.** 수치형×수치형은 Spearman ρ,
범주형×수치형은 √η², 범주형×범주형은 Cramér's V를 씁니다. 하나의 측도를 모든
조합에 강요하면 거짓 발견이 만들어집니다 — 순위화한 연속형 타깃에 Cramér's V를
쓰면 어떤 범주형이든 1.0으로 포화되어 완벽한 누출처럼 보이지만 사실이
아닙니다.

**희소 칼럼은 점수화하지 않고 보고합니다.** 99% 결측 칼럼은 십여 행만으로
완벽한 연관성을 낼 수 있습니다. 완전한 행이 30개 미만이면 프로브는 수치 대신
"점수화 불가"를 반환합니다.

## 캘리브레이션

모든 참조 파일이 예제로 사용하는 `data/ames_housing.csv`로 실행하세요. 참조
본문에 기록된 예상 결과:

- `collinearity_probe.py` — `Gr Liv Area`의 VIF = ∞. `1st Flr SF + 2nd Flr SF
  + Low Qual Fin SF`와 정확히 같기 때문입니다. `Total Bsmt SF`와 세 지하실
  구성 요소도 동일합니다.
- `leakage_probe.py` — `Overall Qual`이 순위 1위이고 구성 요소별 등급
  (`Exter Qual`, `Bsmt Qual`, `Kitchen Qual`)이 바로 뒤에 붙습니다. 등급 요약
  동어반복입니다.
- `null_audit_probe.py` — 차고와 지하실 칼럼군이 정보성 결측을 보입니다
  (|assoc| ≈ 0.28, ≈ 0.20). 그곳의 부재는 "차고 없음 / 지하실 없음"을 뜻하고,
  그 사실 자체가 가격을 예측하기 때문입니다.

## 범위 — 여기 속하는 것과 속하지 않는 것

데이터셋이 바뀌어도 시그니처가 안정적일 때, 즉 DataFrame과 칼럼 역할을 받아
판정을 반환할 때 프로브는 이 디렉터리에 들어올 자격이 있습니다. 위의 모든
검사가 그렇습니다.

분석 코드는 다릅니다. EDA 패스, 변화점 조사, RCA 보고서 스크립트는 칼럼과
질문과 데이터의 형태에 의존하며, 고정된 버전을 포함시키는 것은 작업마다
생성하는 것보다 나쁩니다. 참조 파일들은 그런 것들을 실행할 스크립트가 아니라
의도적으로 적응시킬 패턴으로 담고 있습니다.
